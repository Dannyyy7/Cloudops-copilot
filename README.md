☁️ CloudOps Copilot

AI-Powered DevOps Infrastructure Generator built using Python, Streamlit, and Hugging Face.

🚀 Live Demo

https://cloudops-copilot-w3pcwhqb6gxravcj8waax6.streamlit.app/

📌 Overview

CloudOps Copilot helps DevOps engineers generate production-ready infrastructure code using AI.

Simply enter your project requirements, and the application generates:

- Terraform
- Dockerfile
- Jenkinsfile
- README
- Deployment Steps

✨ Features

- AI-powered DevOps assistant
- Infrastructure code generation
- Terraform generation
- Dockerfile generation
- Jenkins Pipeline generation
- README generation
- Interactive Streamlit web interface
- Secure API integration using Hugging Face

🛠️ Tech Stack

- GitHub

🚀 Installation

Clone the repository

```bash
git clone https://github.com/Dannyyy7/Cloudops-copilot.git
```

Go inside the project

```bash
cd Cloudops-copilot
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
HF_TOKEN=your_huggingface_token
```

Run the application

```bash
streamlit run app.py
```
